# PaperDesk for M5Stack PaperS3

PaperDesk 是运行在 **M5Stack PaperS3** 上的桌面水墨屏固件。设备可选通过 Wi-Fi 联网，提供天气时钟、儿童识字、电子工牌和 Todo，并带有手机可用的配网门户、局域网管理后台和屏上设备设置。

目标硬件：M5Stack PaperS3（ESP32-S3、960×540 水墨屏、触摸屏、16 MB Flash、8 MB PSRAM）。

## 功能

### 设备主菜单

设备解锁后进入竖屏主菜单，无论是否联网都提供五个入口：

1. **时钟**
2. **识字**
3. **工牌**
4. **Todo**
5. **设备设置**

时钟和识字页面使用横屏，工牌、Todo 和主菜单使用竖屏。页面不再根据设备姿态自动切换；在任意内容页面向右滑动即可返回主菜单。

水墨屏完整刷新需要数秒。菜单、设置、Todo 确认和字卡切换等点击操作会先快速弹出“处理中”反馈，再执行目标操作，避免重复点击。

设备启动后先进入竖屏锁屏页，随机显示一条励志名言；从底部方块向右滑动即可解锁。主菜单右上角和设备设置页都可以立即锁屏。

确认关机后，设备会先完整显示“已关机 / 按机身侧键重新开机”，再切断电源，水墨屏不会停留在关机确认页面。

设备设置直接在水墨屏上操作，会显示当前连接的 Wi-Fi 和已保存网络数量；可切换 Wi-Fi 省电、开启或关闭 Web 管理、手动开启配网热点、循环选择自动锁屏时间，也可锁屏、重启或关机。开启 Web 管理时 Wi-Fi 会持续连接；关闭 Web 管理后会停止 HTTP 服务和 `paperdesk.local` 的 mDNS 广播，并在无需同步时关闭 Wi-Fi 射频。需要恢复后台时，从主菜单进入设备设置重新开启即可。

识字、工牌、Todo、主菜单、设备设置与锁屏均不依赖网络。关闭 Web 管理且未开启配网热点时，这些页面会保持 Wi-Fi 关闭。时钟使用设备 RTC 每分钟刷新：每次进入时钟会联网校时并更新天气，持续停留时每小时联网一次，完成后重新关闭 Wi-Fi。

### 天气时钟

横屏天气仪表盘包含：

- 当前温度、天气状态、当天最高/最低温度
- 日出、日落和月相
- 风速与风向
- 日期、时间、湿度、Wi-Fi 与电量
- 未来 8 小时天气与温度
- 温度、降水概率、湿度、气压趋势图

时间每分钟从 RTC 刷新一次；进入时钟时会立即通过 NTP 校时并从 [Open-Meteo](https://open-meteo.com/) 更新天气，之后每小时联网同步一次，不需要 API Key。普通刷新使用快速水墨刷新，每 30 分钟执行一次高质量刷新以减轻残影。

首次配网且尚未设置城市时，设备会通过 [IPWHOIS](https://ipwhois.io/documentation) 按公网 IP 粗略定位城市；定位结果与坐标保存在设备中，不会在每次天气刷新时重复定位。管理后台还提供“按网络自动定位”和“使用手机精确定位”：手机授权定位后，设备通过 [OpenStreetMap Nominatim](https://nominatim.org/release-docs/latest/api/Reverse/) 将坐标反查为城市，并用精确坐标覆盖网络定位。若局域网 HTTP 被浏览器的安全策略禁止调用手机定位，页面会明确提示并自动改用网络定位。

也可以继续手动填写城市，城市名称会经 Open-Meteo 地理编码服务转换为经纬度；手动设置优先，设备以后不会自行覆盖。

### 识字

内置部编版一年级上册写字表 100 字。每张横屏学习卡显示：

- 米字格大字
- 拼音
- 两组常用词
- 简单例句
- 当前进度

点击屏幕左半区切换到上一字，点击右半区切换到下一字，向右滑动返回主菜单。

当前实现为完整字卡，不包含参考项目中的逐笔笔顺动画。

### 电子工牌

工牌字段包括：

- 公司
- 姓名
- 职务
- 编号
- 联系方式

内置 A–F 共 6 套版式：A、B 支持照片，C–F 为纯文字版式。照片可直接从手机或电脑上传，浏览器会自动完成居中裁剪、缩放为 240×240，并转换为适合水墨屏的 16 级灰度图。

### Todo

- 局域网后台添加、删除、排序和标记待办
- 创建、编辑和删除 Todo 模板；模板库数量和模板内条目数不设固定上限
- 勾选一个或多个模板，将整组待办一次导入当前列表
- 每个模板以独立文件保存在设备内置 FFat 分区，管理页分页读取
- Todo 总数不设固定上限，设备端每页显示 10 条，上下滑动翻页
- 当前 Todo 以文件形式保存在设备内置 FFat 分区，管理页分页读取
- 水墨屏 Todo 页可切换“隐藏已完成”，过滤后仍按每页 10 条重新分页
- 水墨屏 Todo 页可清空全部待办，执行前必须二次确认
- 点击待办左侧方框后进入二次确认页面
- 完成状态持久化，并同步到管理后台

## Wi-Fi 配网与管理后台

设备可以记住多个 Wi-Fi，启动后按最近成功连接的顺序自动尝试。附近没有任何已保存网络时，设备直接保持离线，本地功能不受影响；每 5 分钟会低频重试一次，避免持续搜索网络造成额外耗电。

首次启动、清除全部 Wi-Fi 后会自动开启热点；平时如需增加新地点的网络，从“主菜单 → 设备设置 → 开启 Wi-Fi 配网”手动开启：

- 热点名称：`eink-XXXX`，后四位来自设备 MAC 地址
- 热点密码：`xiaocheng2014`
- 配网页面：`http://192.168.4.1/`

手机连接热点后，系统通常会自动打开配网页面。选择 2.4 GHz Wi-Fi、输入密码并提交，设备只会在连接成功后把该网络加入已保存列表，不会覆盖其他地点的 Wi-Fi。

设备已经联网时，点击“开启 Wi-Fi 配网”只会额外开启 `eink-XXXX` 热点，当前 Wi-Fi、IP 和管理后台保持在线；再次点击同一项可关闭配网热点。只有提交另一个网络后，设备才会开始切换连接。

连接家庭网络后，可通过设备获得的 IP 或 `http://paperdesk.local/` 打开管理后台。管理密码默认为 `xiaocheng2014`。后台支持：

- 手动设置天气城市、按公网 IP 自动定位或使用手机坐标校准
- 编辑工牌字段和版式
- 自动处理、预览并上传工牌照片
- 添加、删除、排序和完成 Todo，并管理、批量导入 Todo 模板
- 清除全部已保存 Wi-Fi 并重新进入配网

> 当前热点密码和管理密码为固件内常量。部署到不可信网络前，请修改 `firmware/PaperDesk/AppConfig.h` 中的 `kAdminPassword`。

## 设备交互

| 页面 | 操作 | 效果 |
|---|---|---|
| 主菜单 | 点击卡片 | 进入对应功能 |
| 主菜单 | 点击右上角“锁屏” | 进入随机名言锁屏页 |
| 设备设置 | 点击 Wi-Fi 省电 / Web 管理 | 直接切换对应功能并保存 |
| 设备设置 | 点击开启/关闭 Wi-Fi 配网 | 切换 `eink-XXXX` 配网热点，成功后新增一个已保存网络 |
| 设备设置 | 点击自动锁屏 | 在关闭、5、15、30、60、120 分钟之间循环 |
| 设备设置 | 点击锁屏 / 重启 / 关机 | 执行设备操作，重启和关机需要二次确认 |
| 锁屏 | 从底部方块向右滑动 | 解锁并返回锁屏前页面 |
| 任意内容页面 | 向右滑动 | 返回竖屏主菜单 |
| 识字 | 点击左/右半屏 | 上一字/下一字 |
| Todo | 点击左侧方框 | 打开二次确认 |
| Todo | 点击“隐藏完成” | 切换是否显示已完成待办，不删除数据 |
| Todo | 点击“清空” | 二次确认后永久删除全部待办 |
| Todo | 上滑 / 下滑 | 下一页 / 上一页 |
| 任意页面 | 长按左上角 5 秒 | 清除全部已保存 Wi-Fi 并重启配网 |

扬声器与麦克风在初始化时显式关闭，固件不会测试或驱动蜂鸣器。

[PaperS3 官方说明](https://docs.m5stack.com/en/core/PaperS3)中，机身侧键的硬件行为是单击开机、双击关机；运行中的单击事件不会传递给 ESP32，因此固件不能把侧键单击改写为锁屏。设备每次开机默认进入锁屏页，运行中可通过主菜单或设备设置页锁屏。

## 功耗说明

- 水墨屏保持静态画面几乎不耗电，主要耗电来自 ESP32-S3 持续运行、Wi-Fi 和传感器。
- IMU 在系统初始化后立即进入休眠；当前菜单交互不依赖陀螺仪或加速度计。
- 开启 Web 管理时，固件保持 Wi-Fi 连接并启用 Modem Sleep，首次响应可能稍慢。
- 关闭 Web 管理后，非时钟页面会关闭 Wi-Fi 射频；配网热点开启期间例外。
- 进入时钟会临时联网更新 RTC 和天气，停留期间每小时再联网一次，完成或超时后关闭 Wi-Fi。
- 主循环空闲间隔由 5 ms 调整为 20 ms，减少无意义轮询。
- 时钟仍每分钟刷新一次，高质量全刷仍每 30 分钟执行一次，以兼顾时间准确度和残影控制。
- 锁屏只减少屏幕刷新，不等同于深度睡眠；需要最长续航时可在设备设置页关机，之后按侧键开机。

## 项目结构

```text
firmware/PaperDesk/
├── PaperDesk.ino          # 应用入口、页面状态和触摸交互
├── AppConfig.h            # 密码、时区、刷新周期等配置
├── AppState.*             # 工牌、Todo 与照片持久化
├── ClockView.*            # 水墨屏页面绘制
├── LiteracyContent.*      # 一年级上册 100 字内容
├── WeatherService.*       # 城市解析和 Open-Meteo 天气请求
├── WifiPortal.*           # 配网、Web Server 和管理 API
└── ManagementPage.h       # 内嵌的移动端管理页面
```

小型设置存储在 ESP32 Preferences/NVS 中；工牌灰度照片存储在 FFat 中。

## 开发环境

已验证组合：

- Arduino CLI / Arduino IDE
- M5Stack ESP32 Arduino Core `3.3.9`
- M5Unified `0.2.10`
- M5GFX `0.2.16`
- 开发板 FQBN：`m5stack:esp32:m5stack_papers3`

安装 M5Stack 开发板平台和上述库后，在仓库根目录执行：

```bash
arduino-cli compile \
  --fqbn m5stack:esp32:m5stack_papers3 \
  --build-path .build-paperdesk \
  firmware/PaperDesk
```

## 烧录

先确认串口名称：

```bash
arduino-cli board list
```

然后烧录：

```bash
arduino-cli upload \
  --port /dev/cu.usbmodem14301 \
  --fqbn m5stack:esp32:m5stack_papers3 \
  --input-dir .build-paperdesk \
  firmware/PaperDesk
```

Windows 或 Linux 请将串口替换为实际设备端口。

## 验收建议

1. 首次启动确认出现 `eink-XXXX` 热点并可通过手机完成配网。
2. 无论是否联网，确认设备进入竖屏锁屏页，并可右滑方块解锁。
3. 依次进入时钟、识字、工牌、Todo 和设备设置，并验证右滑返回。
4. 清空天气配置后重启，确认首次联网能按公网 IP 自动定位；再验证手机定位按钮和手动城市设置。
5. 检查识字 100 字的上一字/下一字切换。
6. 分别检查工牌 A–F 版式以及照片上传。
7. 添加 Todo，在设备端完成二次确认，验证隐藏已完成、过滤分页和清空全部的二次确认，再检查后台状态。
8. 在两个不同热点下分别配网，重启并切换地点，确认设备会自动连接已有网络且不会覆盖前一个网络。
9. 关闭全部已保存热点后重启，确认锁屏、主菜单、识字、工牌、Todo 和设备设置仍可离线使用。
10. 在设备设置页验证 Wi-Fi 省电和自动锁屏；关闭 Web 后确认非时钟页面不再连接 Wi-Fi，进入时钟时会短暂联网，完成同步后再次离线。
11. 验证设备设置页的锁屏、重启和关机二次确认。
